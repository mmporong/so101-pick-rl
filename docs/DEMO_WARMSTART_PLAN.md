# 시연 기반 병렬 강화학습 실행 계획

2026-09-18 사용자 승인으로 기존 scratch PPO 제한을 확장한다. 기존 4cm 과제,
체크포인트, 미커밋 파지 진단은 보존한다. 새 실험은 원본 시연의 3cm 박스 배치
과제와 절대 목표각 제어를 기준으로 분리한다. 실물 로봇은 실행하지 않는다.

## 단계와 완료 근거

1. 원본 성공 10회와 Mimic 500회의 숫자 데이터, 초기 상태, 메타데이터를
   읽기 전용으로 추출한다. RGB 원본은 수정하지 않는다. 원본별 출처, 숫자
   데이터 해시, 프레임 정렬 검사, 제외 사유를 기록한다.
2. 같은 초기 상태에서 저장된 모터 목표각을 재생한다. 관측된 다음 관절각을
   목표각으로 대체하지 않는다. 시뮬레이터 버전, 60Hz 시간축, 큐브 자산,
   그리퍼 구동 한계가 다른 환경에 재생 성공을 자동 전이하지 않는다.
3. 재생이 검증된 환경에서 상태 관측으로 actor를 지도 학습한다. 절대 목표각
   라벨의 관절 한계 보정량과 급변 시연을 보고한다. 학습/검증을 에피소드로
   나누고, 공통 원본 시연에서 파생된 검증을 OOD라고 부르지 않는다.
4. 초기 actor에서 실제 다중 환경 PPO를 실행한다. 시연 재생, Mimic 생성,
   BC와 PPO의 업데이트 수를 구분한다. 물체 부착이나 강제 상태 이동은 reset
   외에 사용하지 않는다. 물리 검증에 실패한 실험을 확대하지 않는다.
5. 고정된 평가 조건에서 전체 Pick & Place와 실패를 보고한다. 열기, 접근,
   파지, 들기, 운반, 배치, 해제 및 안정 유지가 확인되지 않으면 완료가 아니다.
   영상과 대용량 데이터는 Git에 넣지 않는다.

## 확인된 실행 환경

- Windows: Isaac Sim 4.5 / Isaac Lab 2.1.1, RTX 3060 12GB.
- ASUS 원본 환경 실측: Isaac Sim 5.1.0 / Isaac Lab 2.3.0,
  PyTorch 2.7.0+cu128, RTX 5050 Laptop.
- 원본 HDF5 메타데이터: physics dt=1/60초, decimation=1.
- 원본 위치: ASUS의 `/data/lim/leisaac/datasets/pick_cube_into_box_source_10_20260911.hdf5`.
- Mimic 위치: `/data/lim/leisaac/outputs/mimic_vision224_500_20260913/raw/`.
- 병행 작업이 원격 저장소에서 실행 중이므로 원격 소스/모델을 덮어쓰거나
  타 작업 프로세스를 종료하지 않는다. 별도 출력만 사용한다.

원격 `contract_hardening_20260918/replay_stable_release/evaluation.json`에서
demo_0/1/2의 stable_release_v2 재생 3/3을 읽었다. 이 수치는 기존 작업의
원본 환경 재생 결과이며 새 정책, Windows 환경, 접촉 침투 감사의 통과가 아니다.

## 현재 진행

Native Codex goal을 생성했다. 원본 파일 존재와 스키마를 확인했고 숫자 추출기를
구현했다. 원격 접속이 중간에 끊겨 파일 전송과 새 학습은 아직 시작하지 않았다.
재접속 후 이 기록을 실측 결과로 갱신한다.

숫자 추출 파일은 원본의 이미지 없는 복사본이며 학습 준비가 끝난 데이터가 아니다.
`demo_action_contract.aligned_targets`는 목표각을 T−1 전이에 정렬하고 범위·급변을
검사하는 유틸리티다. 환경 replay, 학습용 state-action loader, BC와 PPO 연결부는
아직 구현하지 않았다. 기존 학습 진입점에 이 파일을 입력해 실행하지 않는다.
학습 어댑터는 배열의 6열을 믿고 연결하지 말고 시뮬레이터 관절 이름·순서를
`JOINT_NAMES`와 대조해야 한다. 관절 한계의 출처와 SHA-256도 실행 기록에 남긴다.
범위를 벗어난 목표각은 현재 감사 도구에서 거부한다. 보정이 필요하면 raw를
보존한 별도 파생 라벨에 보정량·제외 기준을 기록하고 재생으로 검증해야 한다.

## 데이터 접근 재개

원본에는 실패 1회가 섞여 있으므로 성공 10회 추출 때만
`--skip-failed-episodes`를 명시한다. 제외된 시연은 manifest에 남긴다.
500회 raw 묶음은 성공 shard만 선택하고 실패 파일은 별도 보존한다.
모든 출력에는 새 이름을 사용하며, 원본 HDF5·기존 출력·원격 소스를 수정하지 않는다.

HDF5 검사에는 Isaac Sim에 이미 설치된 h5py를 사용한다. Windows의 일반
Python 3.14에는 h5py가 없어 해당 테스트를 실행할 수 없으며, 전역 패키지는 설치하지 않는다.
